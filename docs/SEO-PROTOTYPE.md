# Прототип: prerender + языковые URL (React Router framework mode)

Ветка `feat/seo-prerender-prototype`, draft PR. Стек прежний (Vite + React Router 7), добавлены
prerender, языковые URL и автопересборка. Не финальная версия — см. «Перед публикацией».
Откат — [ROLLBACK.md](ROLLBACK.md), автопересборка — [AUTO-REBUILD.md](AUTO-REBUILD.md),
тексты мета для вычитки — [SEO-META-TEXTS.md](SEO-META-TEXTS.md),
план проверки на настоящем Vercel — [VERCEL-E2E-PLAN.md](VERCEL-E2E-PLAN.md).
Результаты проверки Preview на окончательном коммите (с точным SHA) — в описании PR.

## Что реализовано

- **Рендеринг.** `ssr:false` + `prerender()` (`FE/react-router.config.ts`): все страницы × 3 языка
  и все объекты из API. Нет ответа API при сборке — сборка падает, прежний деплой остаётся.
- **Языки.** `/` = DE (прежние URL), `/en/…`, `/ru/…`; `/de/…` и другие префиксы — 404. Язык задаёт
  URL; `<html lang>` верный и в HTML, и после гидратации.
- **Мета** — уникальные title, description, self-canonical, OG на всех публичных страницах;
  hreflang только между готовыми языками (`FE/src/seo/*`, тексты в `locales/*.json → seo`).
- **Реестр готовности языков** `FE/src/seo/readiness.json` — единый источник для hreflang,
  `noindex` и sitemap. **Индексацию неготовых версий я не включал.**
- **Ссылки и переключатель** сохраняют язык; **404** — полноценная страница; **H1** есть на всех
  публичных страницах; **единый trailing slash** (без слэша); **без дублей запросов** loader/хук.
- **Автопересборка** — хук после сохранения объекта + сверка с опубликованным сайтом.

## Готовность языковых версий (по содержанию)

Критерий — не совпадение строк, а всё содержимое страницы: (1) автоматическое сравнение всего
видимого текста DE/EN/RU, (2) немецкие строки, зашитые в коде страниц, (3) структура переводов
(ключи, массивы, цифры, плейсхолдеры), (4) чтение переводов на смысл, (5) **интерактивные
состояния** — для калькулятора проверены 8–9 состояний (ввод, ошибки диапазона, пустое поле,
несоответствие цены и капитала, пользовательский процент, окна с пояснениями, результат), для
формы контакта — пустая отправка (запросы не отправлялись).

| Страница | EN/RU | Основание |
|---|---|---|
| Home, Wertermittlung, Kontakt, Verkaufssupport, Recht & Rat, **Finanzierung, Rechner** | **готовы** | видимый текст, формы, валидация и состояния переведены; структура и цифры совпадают |
| Immobilien (список), карточки объектов | **noindex** | данные объектов в API только по-немецки |
| Objektstyling, Impressum, Datenschutz, Widerruf | **noindex** | тексты только по-немецки |
| Danke, админ-маршруты | **noindex** (все языки) | служебные |

**Поправка к прежнему выводу.** Раньше я понижал `/finanzierung` и `/rechner` из-за четырёх
немецких сообщений в `MortgageCalculator.tsx`. На самом деле эти строки записывались в состояние,
но **нигде не показывались** (на экране выводится уже переведённый `validationHint`). Строки всё
равно переведены через i18n (два существующих ключа + два новых: `equityRequired`,
`customFieldsInvalid`), а готовность определена по фактически видимому содержимому: в 9 состояниях
EN/RU нет ни одной строки, совпадающей с немецкой, — страницы возвращены в «готово».

**Приведение EN/RU Home к немецкому оригиналу** (новых фактов нет): «о нас» — добавлено «более 40 лет»
(было опущено); «успешная продажа» → «успешное завершение» (нем. Abschluss); «готовая и строящаяся
недвижимость» → «вторичная и новая» (Bestands-/Neubau); «коммерческим объектам» → «коммерческим
зданиям» (Geschäftshäuser); «ценные инвестиции / high-value» → «высококачественные / high-quality»
(hochwertig); FAQ о Geschäftshaus: «доходный дом» → «коммерческое здание»; FAQ RU «оформление
поручения» → «заключение договора» (как в шагах); кнопка шагов «Sell/Продать» → «Selling/Продажа»
(нем. «Verkauf»); категория EN «Legal advice» → «Law and advice» (нем. «Recht und Rat»).

Оставшиеся недочёты (не менялись):

- Форма контакта: при ошибке отправки показывается сообщение backend (по-немецки); запасной текст
  `contactForm.submitError` недостижим (`model.ts` всегда бросает ошибку с текстом).
- Суммы в калькуляторе во всех языках форматируются по-немецки (`540.178,50`); EN-читателю точка
  как разделитель тысяч может быть непривычна.
- PDF-экспорт калькулятора: подписи берутся из переведённых ключей, сам файл при проверке не
  формировался.
- EN-заголовок страницы Recht & Rat — «Legal Advice» (контент страницы, вне Home; мета-тексты
  нарочно нейтральны).
- `alt`-тексты части картинок и JSON-LD `Service` на Wertermittlung (`Valuation.tsx`) — по-немецки
  (не видны на странице); `contactForm.captchaNotConfigured` (RU) упоминает `.env`.

## Результаты проверок

**Сборка и типы:** `npm run build` (с `VITE_RECAPTCHA_SITE_KEY`, как на Vercel), `tsc -b` — без
ошибок. Backend: `npm run test:rebuild` — 21 из 21. `npm run lint` в этом окружении не запускается
(нет `eslint-plugin-react`) — не проверено. **Сквозной тест автопересборки: 24 из 24**
(изолированное окружение, [AUTO-REBUILD.md](AUTO-REBUILD.md)).

**H1:** на `/finanzierung`, `/kontakt`, `/verkaufssupport`, `/rechner` и их EN/RU версиях ровно один H1
(существующие заголовки: калькулятора, формы, баннера «Verkaufssupport»; на `/finanzierung`
заголовок формы остаётся H2). Сравнение вычисленных стилей до/после (19 свойств, ширины 1280 и 390):
**различий нет**.

**HTML, sitemap, hreflang:** у каждой публичной страницы есть title, description, canonical, OG,
`<html lang>`, контент без JS. Sitemap — только готовые языки и собранные объекты; hreflang — только
у страниц с ≥ 2 готовыми языками (7 страниц × 3 языка). Sitemap: 30 URL = 12 страниц DE + 4 объекта DE + 14 EN/RU (7 готовых страниц × 2), 84 hreflang-связи.

**Языковые переходы, 404, запросы:** см. описание PR (проверено на локальной сборке и на Vercel
Preview окончательного коммита).

## Известные ограничения и не проверено

- **Автопересборка проверена только в изолированном окружении**, не с реальным Vercel и боевым
  backend. Новый объект появляется после успешной пересборки (минуты); до этого его URL отдаёт 404.
- Карта на карточке не показывается (запрос к `restcountries.com` не проходит) — так же на
  production; не исправлялось.
- Редизайн Home, старый домен `immo-tonn.de` не менялись.
- Консоль на Preview проверяется частично (инструмент сбрасывает записи при переходах).
- Старые `src/app/App.tsx`, `main.tsx`, `index.html`, `Seo.tsx` не используются, оставлены.
- `href` переключателя языка в prerender-HTML не содержит `?query` (клик сохраняет параметры).

## Перед публикацией

1. Решить по индексации EN/RU объектов и неготовых страниц (сейчас `noindex`; без переводов объектов и
   страниц Objektstyling и юридических текстов включать нельзя).
2. Вычитать мета-тексты ([SEO-META-TEXTS.md](SEO-META-TEXTS.md)) и правки из раздела недочётов.
3. Пройти проверку на настоящем Vercel по [VERCEL-E2E-PLAN.md](VERCEL-E2E-PLAN.md) (требует ваших
   решений); хук на `dev` — только после слияния.
4. Production Branch в Vercel подтверждён: `dev`. Проверить значения `VITE_HOST` и ключа reCAPTCHA для Production и Preview (в Preview `VITE_HOST` не привязан к ветке).
5. После слияния (= публикация): проверить Production тем же набором, отправить sitemap в Search
   Console; откат — по ROLLBACK.md.
6. Отдельно: старый `immo-tonn.de`; затем перенос редизайна Home.
